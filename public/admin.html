🎥 HƯỚNG DẪN CÀI ĐẶT OBS STUDIO / TIKTOK LIVE STUDIO
  1. Mở OBS Studio hoặc TikTok LIVE Studio.
  2. Thêm nguồn Trình duyệt (Browser Source) mới.
  3. Dán đường dẫn URL: http://localhost:3000/
  4. Đặt chiều rộng: 1080, chiều cao: 1920 (chuẩn tỉ lệ 9:16 TikTok).
  5. Tích chọn "Điều khiển âm thanh qua OBS" (Control audio via OBS) nếu muốn chỉnh âm lượng bài hát trực tiếp trên OBS Mixer.
  6. Mở tab này (http://localhost:3000/admin.html) trên màn hình phụ hoặc điện thoại để điều khiển live!
